# The Winter Guide

Shoppable winter lookbook by Ericka Tamez and Maria Tricio (preview for approval). One static page: `index.html` + transparent garment cutouts in `img/`.

- Pages: `#home` (every look), one page per occasion (`#ski-trip`, `#nye`, …) and `#shop` (View by product).
- Looks live in the `OCC` array. Each look has a `title` (placeholder until the real names arrive), `pieces` (cutout + position) and `items` (shop cards with ShopMy links; `""` = link coming soon).
- Each copy shows a watermark with the buyer's name and email (`BUYER` in the script).
