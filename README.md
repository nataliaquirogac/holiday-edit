# The Holiday Edit

Shoppable Christmas lookbook (preview for approval). One static page: `index.html` + product cutouts in `img/`.

- Outfits are assembled from cutouts in the `LOOKS` array (`body` = position on the figure, `items` = shop drawer cards).
- Brands, pieces and buyer name are sample data until the real looks arrive.
- Each copy shows a watermark with the buyer's name and email (`BUYER` in the script).
